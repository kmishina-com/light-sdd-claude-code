# 人の指摘のとおりに文書を直す

引数: $ARGUMENTS

1つ目の語が文書のパス、残りが人の指摘である。

## 手順

1. 文書を読み、指摘を1つずつ反映する。指摘に無い箇所は直さない。
2. 受け入れ条件を直した場合は、その条件の確認方法も合うように直す。番号の振り直しが要る場合は、文書の中で番号を指している箇所もそろえる。
3. 直した結果、ほかに直す必要がありそうな箇所（文書内の食い違い、古くなった参照）があれば、**直さずに**報告に挙げる。
4. 報告して止まる。指摘された文書以外は変更しない。コミットしない。

## 報告に書くこと

- 指摘ごとの反映結果（反映した箇所）
- ほかに直す必要がありそうな箇所（直していない）
- 実行しなかった指摘（あれば、名指しで理由付き）
